|15Full-screen editor|07

Type to enter text: lines wrap by themselves, press |11Enter|07 only to
start a new paragraph.  Move anywhere with the arrow keys, |11Home|07,
|11End|07, |11PgUp|07 and |11PgDn|07.  |11Ctrl-Left|07 and |11Ctrl-Right|07 move by word.

|10Commands|07, by control key, or by |11Esc|07 for a menu:

   |11^Z|07  save and exit
   |11^A|07  abort, discarding your text
   |11^Q|07  quote the message you are replying to
   |11^G|07  this help

|10Editing|07:

   |11Backspace|07   delete character left of the cursor
   |11Delete|07, |11^D|07  delete character under the cursor
   |11^W|07          delete word left of the cursor
   |11^Y|07          cut the current line, repeat to cut several
   |11^U|07          paste cut lines above the current line
   |11^V|07, |11Insert|07  switch between insert and overwrite
   |11Esc|07, |11U|07      undo
   |11^L|07          redraw the screen

|10Quoting|07: |11^Q|07 shows the message you are replying to.  Move with
the arrow keys, mark lines with |11Space|07 (|11A|07 marks all), and press
|11Enter|07 to insert the marked lines, or the current line when none
are marked.  |11Esc|07 returns without quoting.

|10Colors|07: enter a '||' followed by two digits to change the color of
the text that follows:

   ||00 |00Black|07       ||04 |04Red|07          ||08 |08Dark gray|07   ||12 |12Light red|07
   ||01 |01Blue|07        ||05 |05Magenta|07      ||09 |09Light blue|07  ||13 |13Light magenta|07
   ||02 |02Green|07       ||06 |06Brown|07        ||10 |10Light green|07 ||14 |14Yellow|07
   ||03 |03Cyan|07        ||07 |07Light gray|07   ||11 |11Light cyan|07  ||15 |15White|07

Codes ||16 through ||255 select colors of 256-color terminals.  Enter
'||||' for a '||' character itself.
